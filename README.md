
##  ‼️ 작업 전에 반드시 확인하세요 <br><br>
### ✅ 작업 전 Issue 탭에서 자신이 진행할 개발 내용을 템플릿에 맞게 작성 후 진행해주세요.
#### ⭐ Issue 제목은 Issue 탭 내 샘플 양식을 참조하여 작성합니다.
<br>

### ✅ 항상 기능 추가 작업 시 develop 아래에 작업브랜치 (feature .. ) 를 생성해서 진행합니다.
#### ⭐ 항상 작업브랜치 (feature.. ) 생성 시 뒤의 이름은 **"!이슈번호!"** 로 작성하세요 (ex : feature/2)
<br>

### ✅ 작업 브랜치에서 작업이 끝난 뒤 상위 브랜치로 Merge 시 PR을 반드시 양식에 맞게 작성합니다.
#### ⭐ PR 작성 후 반드시 한명이상 리뷰를 받고 이상이 없는 경우 Merge 하세요.
